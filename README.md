# Chat App

A Spring Boot chat application built with WebSockets for real-time messaging.

## Description

This project is a chat application backend built using Spring Boot and WebSockets technology, enabling real-time communication between multiple users.

## Features

- Real-time messaging using WebSockets
- Spring Boot framework
- Multi-user support

## Technology Stack

- **Framework**: Spring Boot
- **Communication**: WebSockets
- **Build Tool**: Maven
- **Language**: Java

## Getting Started

### Prerequisites

- Java JDK 11 or higher
- Maven 3.6 or higher

### Installation

1. Clone the repository
```bash
git clone https://github.com/rahimkechemir/chatapp.git
cd chatapp
```

2. Build the project
```bash
./mvnw clean package
```

3. Run the application
```bash
./mvnw spring-boot:run
```

The application will start and be available at `http://localhost:8080`

## Project Structure

- `src/` - Source code directory
- `.mvn/` - Maven wrapper configuration
- `pom.xml` - Project dependencies and build configuration
- `mvnw` - Maven wrapper script for Unix/Linux
- `mvnw.cmd` - Maven wrapper script for Windows
